# Development status

## v0.10 public test

- Unified installer, optional DLCs, content-package extraction, tool detection, progress, cleanup and standard/offline packages.
- English launcher, seven original game languages, persistent settings and release update checks.
- Startup splash image sequence disabled before its first displayed frame.
- Controller/keyboard mapping, two-player native split-screen and bots.
- Video scaling, higher-FPS physics correction, VSync, FPS counter, HDR10 conversion and experimental temporal upscalers.
- EOS public/private/co-op integration, native matchmaking, Epic overlay invitations, achievement and leaderboard bridges.

## Community validation

- Real invite acceptance, public Epic access and overlay on fresh PCs.
- Full rounds, scoring, achievements and leaderboard read-back.
- Multiple hosts and ping selection across real networks; larger online sessions, co-op and long sessions.
- DLC maps, controller models and video settings across more hardware.

## Future work

- HUD separation and object motion vectors for temporal upscaling.
- Four-player local cameras/rendering.
- Leaderboard pagination/friend filters and weekly service scheduling.
- Linux/Android and cross-platform validation.

See [EOS](EOS.md), [Multiplayer](MULTIPLAYER.md), [Video](VIDEO.md) and [Leaderboards](LEADERBOARDS.md). File reproducible problems in Issues. Planned checks are not completed features.
